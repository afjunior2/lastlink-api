\## 🚀 How to Run



\### Prerequisites

\- .NET 8.0 SDK

\- Docker (optional)



\### Local Execution

```bash

\# Clone repository

git clone https://github.com/afjunior2/lastlink-api.git



cd lastlink-api



\# Restore dependencies

dotnet restore



\# Run application

cd LastLinkApi.Api

dotnet run --urls="http://0.0.0.0:8080"
